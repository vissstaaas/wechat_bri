## 一、 用户核心需求与演进历程

### 1. 核心业务痛点
1. **备忘录中转延迟痛点**：
   - 用户尝试通过 iPhone【快捷指令】在收到短信时自动追加到备忘录《信息转发》，再由电脑轮询推送到微信。
   - **痛点**：端到端延迟高达 1~2 分钟，偶尔漏内容或延迟严重，体验极差。
   - **根因分析**：iOS 的 iCloud 守护进程（`cloudd`）为了保证电池续航，在后台绝对不会实时上传新增的备忘录，而是进行 30s ~ 120s 的节流排队，直到前台打开备忘录或系统空闲才上传。
2. **局域网绑定痛点**：
   - 若直接通过快捷指令发出本地 IP Webhook（如 `http://192.168.0.173:3080/api/sms/inbound`），用户一旦离开家或切到 4G/5G 蜂窝网络，手机立即与电脑断联无法触发。
   - **需求**：必须支持跨网段/全公网（异地 5G、公司 Wi-Fi 等）场景下的极速流转。
3. **大模型强绑定与环境兼容性诉求**：
   - 当前系统默认接入了用户本地的 Magpie 网关（`127.0.0.1:3425` DeepSeek-v4.1-flash）。
   - **用户明确要求**：大模型必须是**完全可选、可插拔的**，因为不是所有使用者都有本地大模型运行环境；系统核心能力不能假设依赖本地 GPU 或第三方网关。
4. **实时可视化感知（Magpie 风格拓扑流）**：
   - 用户希望直观看到系统每一笔请求的实时决策过程，参考 Magpie 的暗色极客 UI、贝塞尔流光连线、请求耗时细分柱状图和决策溯源文字。

## 二、 核心架构设计与工程落地

### 1. 实时流转中枢与拓扑舞台 (Magpie-Style)
- **多模态四入口 (Inbound Sources)**：
  - 🎙️ iPhone Siri 语音口令
  - 💬 微信 ClawBot 聊天通道
  - 📱 手机短信快捷指令
  - 🖥️ Web 控制台 / Playground
- **核心智能分流网关 (DualModeRouter Hub)**：
  - 基于纯算法的特征关键词打分与正则引擎（< 2ms 延迟，0 显存，0 依赖）。
  - 精准识别：待办取件码、账号密码凭据、链接稍后读、灵感笔记、AI 问答。
- **五大多端执行宿主 (Execution Sinks)**：
  - 🤖 本地大模型网关（Magpie / Ollama / LMStudio）
  - 📄 Apple Notes 备忘录四大家族（本地即时写 + 异步 iCloud 推送）
  - 📁 iCloud Drive 云盘文件直传与提取
  - 🖼️ 相册视觉 OCR 与原图互传
  - 📲 手机微信即时通知卡片
- **底层通信技术**：
  - 内存事件总线 `TraceBus.js` + 原生 SSE `/api/stream`。
  - 前端 SVG 动态贝塞尔曲线（`C mx y1, mx y2`），支持请求生命周期的全链路霓虹流光脉冲与多连线并发常亮。

### 2. 本地大模型彻底解耦架构 (Three-Tier Pluggable LLM)
1. **Tier 1: 纯内置规则与意图引擎 (Built-in Rule Engine, 默认)**
   - 短信智能分类、备忘录归档、待办生成、链接保存、Siri 快捷查询检索全部由此层处理。
   - **完全不依赖任何外部大模型**，即使无显卡、无外部网关，也能开箱即用。
2. **Tier 2: 本地大模型网关 (Local Gateway, 可选)**
   - 适配 Magpie (`127.0.0.1:3425`) / Ollama / LMStudio。
   - 具备探针自检与超时保护（3000ms），若本地网关未启动则静默降级，不阻塞主流程。
3. **Tier 3: 云端标准 API (Cloud API, 可选)**
   - 支持标准 OpenAI / DeepSeek 协议配置（BaseURL + API Key）。

### 3. 短信流转方案评估与选型矩阵

| 方案 | 流程链路 | 端到端延迟 | 网络限制 | 适用人群与评价 |
| :--- | :--- | :--- | :--- | :--- |
| **A. 备忘录中转 (原生)** | 短信 ➔ 写入 iPhone 备忘录 ➔ iCloud 云端排队 ➔ 电脑拉取 ➔ 微信 | 60s ~ 150s (约2分钟) | 任意网络 (原生离线) | 追求 0 配置、不装任何额外软件，但必须容忍苹果 CloudKit 后台节流延迟。 |
| **B. Tailscale 异网 Webhook (推荐)** | 短信 ➔ 快捷指令 POST `http://100.116.191.26:3080/api/sms/inbound` ➔ 微信 | **< 400 毫秒** | 任意 4G/5G/Wi-Fi | 极速秒级响应，点对点加密，无公网暴露风险。 |
| **C. 公网穿透 Tunnel** | 短信 ➔ 快捷指令 POST `https://*.trycloudflare.com/api/sms/inbound` ➔ 微信 | **< 300 毫秒** | 任意 4G/5G/Wi-Fi | 电脑端运行 cloudflared 快速生成固定 HTTPS 链接，手机开箱即用。 |
| **D. 快捷指令静默邮件** | 短信 ➔ 快捷指令后台静默发信 ➔ 邮件服务器 ➔ 微信/备忘录 | 3s ~ 8s | 任意网络 | 手机端无需安装任何额外 App，利用 iOS 内置邮件后台发送。 |
